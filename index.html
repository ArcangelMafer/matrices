🎀 Métodos Algebraicos para Sistemas de Ecuaciones

📖 ¿Qué es un sistema de ecuaciones lineales?

Un sistema de ecuaciones lineales es un conjunto de dos o más ecuaciones que comparten las mismas variables. Nuestro objetivo es encontrar los valores de estas variables que satisfagan todas las ecuaciones al mismo tiempo.

Sistema 2×2:
a₁x + b₁y = c₁
a₂x + b₂y = c₂
💡 Nota de Pusheen: ¡Imagina que cada ecuación es una línea! La solución es donde se cruzan estas líneas. ¡Miau! 🐱

🌟 Método de Sustitución

Este método consiste en despejar una variable de una ecuación y sustituirla en la otra.

→ 📝

Pasos:

  1. Despeja una variable de cualquiera de las ecuaciones
  2. Sustituye esa expresión en la otra ecuación
  3. Resuelve la ecuación resultante
  4. Sustituye el valor encontrado en cualquier ecuación para hallar la otra variable

✨ Ejemplo Resuelto - Método de Sustitución

Resolver:

2x + y = 7
x - y = 2
Paso 1: Despejamos y de la primera ecuación
y = 7 - 2x
Paso 2: Sustituimos en la segunda ecuación
x - (7 - 2x) = 2
x - 7 + 2x = 2
3x = 9
x = 3
Paso 3: Sustituimos x = 3 en y = 7 - 2x
y = 7 - 2(3)
y = 7 - 6
y = 1
✅ Solución: x = 3, y = 1
🎀 Verificación:
2(3) + 1 = 7 ✓
3 - 1 = 2 ✓
✨

🌸 Método de Igualación

Este método consiste en despejar la misma variable de ambas ecuaciones e igualar las expresiones.

Pasos:

  1. Despeja la misma variable de ambas ecuaciones
  2. Iguala las dos expresiones obtenidas
  3. Resuelve la ecuación resultante
  4. Sustituye el valor encontrado para hallar la otra variable

✨ Ejemplo Resuelto - Método de Igualación

Resolver:

3x + 2y = 12
2x + y = 7
Paso 1: Despejamos y de ambas ecuaciones
De la primera: 2y = 12 - 3x → y = (12 - 3x)/2
De la segunda: y = 7 - 2x
Paso 2: Igualamos
(12 - 3x)/2 = 7 - 2x
Paso 3: Resolvemos
12 - 3x = 2(7 - 2x)
12 - 3x = 14 - 4x
4x - 3x = 14 - 12
x = 2
Paso 4: Sustituimos x = 2
y = 7 - 2(2)
y = 7 - 4
y = 3
✅ Solución: x = 2, y = 3
💕

💖 Método de Reducción (Eliminación)

Este método consiste en multiplicar las ecuaciones por números adecuados para que al sumarlas o restarlas, se elimine una variable.

Pasos:

  1. Multiplica una o ambas ecuaciones por números que hagan iguales los coeficientes de una variable
  2. Suma o resta las ecuaciones para eliminar esa variable
  3. Resuelve la ecuación de una variable resultante
  4. Sustituye el valor encontrado para hallar la otra variable

✨ Ejemplo Resuelto - Método de Reducción

Resolver:

4x + 3y = 18
2x - y = 4
Paso 1: Multiplicamos la segunda ecuación por 3
4x + 3y = 18
6x - 3y = 12
Paso 2: Sumamos ambas ecuaciones
(4x + 3y) + (6x - 3y) = 18 + 12
10x = 30
x = 3
Paso 3: Sustituimos x = 3 en 2x - y = 4
2(3) - y = 4
6 - y = 4
y = 2
✅ Solución: x = 3, y = 2
✨💕

🎀 Operaciones con Matrices

📖 ¿Qué es una Matriz?

Una matriz es un arreglo rectangular de números organizados en filas y columnas. Se representa con letras mayúsculas.

Matriz A de orden 2×3:

A = [ a₁₁ a₁₂ a₁₃ ]
    [ a₂₁ a₂₂ a₂₃ ]
💡 Nota de Pusheen: El orden de una matriz se escribe como filas × columnas. ¡Es como una cuadrícula de gatitos! 🐱

➕ Suma y Resta de Matrices

Dos matrices se pueden sumar o restar solo si tienen el mismo orden. La operación se realiza elemento a elemento.

Si A = [aᵢⱼ] y B = [bᵢⱼ]
Entonces: A ± B = [aᵢⱼ ± bᵢⱼ]

✨ Ejemplo Resuelto - Suma de Matrices

Datos:
A = [ 2 3 ]    B = [ 1 4 ]
    [ 1 5 ]       [ 2 3 ]
Solución:
A + B = [ 2+1 3+4 ]
        [ 1+2 5+3 ]
✅ Resultado:
A + B = [ 3 7 ]
        [ 3 8 ]
➕ = 💕

✖️ Multiplicación de una Matriz por un Escalar

Para multiplicar una matriz por un número (escalar), multiplicamos cada elemento de la matriz por ese número.

k · A = [k · aᵢⱼ]

✨ Ejemplo Resuelto - Producto por Escalar

Datos:
A = [ 2 -1 ]    k = 3
    [ 4 3 ]
Solución:
3 · A = [ 3(2) 3(-1) ]
        [ 3(4) 3(3) ]
✅ Resultado:
3 · A = [ 6 -3 ]
        [ 12 9 ]

🔢 Multiplicación de Matrices

Dos matrices A y B se pueden multiplicar si el número de columnas de A es igual al número de filas de B.

Si A es m×n y B es n×p
Entonces: C = A · B es m×p

cᵢⱼ = Σ(aᵢₖ · bₖⱼ)
💡 Nota de Pusheen: Cada elemento de C se obtiene multiplicando fila por columna. ¡Es como hacer sumas de productos! 🐱✨

✨ Ejemplo Resuelto - Multiplicación de Matrices

Datos:
A = [ 1 2 ]    B = [ 3 1 ]
    [ 3 4 ]       [ 2 5 ]
Paso 1: Elemento c₁₁ (fila 1 × columna 1)
c₁₁ = 1(3) + 2(2) = 3 + 4 = 7
Paso 2: Elemento c₁₂ (fila 1 × columna 2)
c₁₂ = 1(1) + 2(5) = 1 + 10 = 11
Paso 3: Elemento c₂₁ (fila 2 × columna 1)
c₂₁ = 3(3) + 4(2) = 9 + 8 = 17
Paso 4: Elemento c₂₂ (fila 2 × columna 2)
c₂₂ = 3(1) + 4(5) = 3 + 20 = 23
✅ Resultado:
A · B = [ 7 11 ]
        [ 17 23 ]

🔄 Matriz Identidad y Matriz Inversa

Matriz Identidad (I): Es una matriz cuadrada con unos en la diagonal principal y ceros en el resto.

I₂ = [ 1 0 ]    I₃ = [ 1 0 0 ]
     [ 0 1 ]         [ 0 1 0 ]
                            [ 0 0 1 ]

Matriz Inversa (A⁻¹): Es la matriz que al multiplicarla por A da la matriz identidad.

A · A⁻¹ = I
💡 Nota de Pusheen: No todas las matrices tienen inversa. Solo las matrices cuadradas con determinante ≠ 0 tienen inversa. ¡Miau! 🐱

✨ Ejemplo - Matriz Inversa 2×2

Para una matriz 2×2, la fórmula de la inversa es:

Si A = [ a b ]
       [ c d ]

A⁻¹ = (1/det(A)) · [ d -b ]
                        [ -c a ]

donde det(A) = ad - bc
Ejemplo: Encontrar A⁻¹
A = [ 2 1 ]
    [ 3 4 ]
Paso 1: Calculamos det(A)
det(A) = (2)(4) - (1)(3) = 8 - 3 = 5
Paso 2: Aplicamos la fórmula
A⁻¹ = (1/5) · [ 4 -1 ]
                [ -3 2 ]
✅ Resultado:
A⁻¹ = [ 4/5 -1/5 ]
       [ -3/5 2/5 ]
💕✨

🎀 Método de Cramer

📖 ¿Qué es el Método de Cramer?

El método de Cramer es una técnica para resolver sistemas de ecuaciones lineales usando determinantes. Es muy útil cuando el sistema tiene una solución única.

💡 Nota de Pusheen: ¡Este método usa determinantes! Primero necesitamos saber calcularlos. ¡Miau! 🐱

🔢 Determinantes

Determinante de una matriz 2×2:

A = [ a b ]
    [ c d ]

det(A) = |A| = ad - bc

Determinante de una matriz 3×3 (Regla de Sarrus):

A = [ a b c ]
    [ d e f ]
    [ g h i ]

det(A) = aei + bfg + cdh - ceg - afh - bdi

✨ Ejemplo - Determinante 2×2

Datos:
A = [ 3 2 ]
    [ 1 4 ]
Solución:
det(A) = (3)(4) - (2)(1)
det(A) = 12 - 2
det(A) = 10
✅ Resultado: det(A) = 10
🔢

✨ Ejemplo - Determinante 3×3

Datos:
A = [ 2 1 3 ]
    [ 1 2 1 ]
    [ 3 1 2 ]
Paso 1: Productos positivos (diagonal principal y paralelas)
(+) = (2)(2)(2) + (1)(1)(3) + (3)(1)(1)
(+) = 8 + 3 + 3 = 14
Paso 2: Productos negativos (diagonal secundaria y paralelas)
(-) = (3)(2)(3) + (2)(1)(1) + (1)(1)(2)
(-) = 18 + 2 + 2 = 22
Paso 3: Determinante
det(A) = 14 - 22 = -8
✅ Resultado: det(A) = -8

🌟 Fórmula del Método de Cramer

Para un sistema de ecuaciones lineales AX = B, donde A es la matriz de coeficientes:

x₁ = det(A₁) / det(A)
x₂ = det(A₂) / det(A)
x₃ = det(A₃) / det(A)
...

donde Aᵢ es la matriz A con la columna i reemplazada por B
⚠️ Importante: El método solo funciona si det(A) ≠ 0. Si det(A) = 0, el sistema no tiene solución única.

✨ Ejemplo Completo - Sistema 2×2 con Cramer

Resolver:

2x + 3y = 8
x - y = 1
Paso 1: Matriz de coeficientes A y vector B
A = [ 2 3 ]    B = [ 8 ]
    [ 1 -1 ]       [ 1 ]
Paso 2: Calculamos det(A)
det(A) = (2)(-1) - (3)(1)
det(A) = -2 - 3 = -5
Paso 3: Matriz A₁ (reemplazamos columna 1 con B)
A₁ = [ 8 3 ]
     [ 1 -1 ]

det(A₁) = (8)(-1) - (3)(1) = -8 - 3 = -11
Paso 4: Matriz A₂ (reemplazamos columna 2 con B)
A₂ = [ 2 8 ]
     [ 1 1 ]

det(A₂) = (2)(1) - (8)(1) = 2 - 8 = -6
Paso 5: Aplicamos las fórmulas
x = det(A₁) / det(A) = -11 / -5 = 11/5 = 2.2
y = det(A₂) / det(A) = -6 / -5 = 6/5 = 1.2
✅ Solución: x = 2.2, y = 1.2
🎀 Verificación:
2(2.2) + 3(1.2) = 4.4 + 3.6 = 8 ✓
2.2 - 1.2 = 1 ✓
✨💕

✨ Ejemplo Completo - Sistema 3×3 con Cramer

Resolver:

x + 2y + z = 6
2x + y - z = 1
x - y + 2z = 5
Paso 1: Matriz A y vector B
A = [ 1 2 1 ]    B = [ 6 ]
    [ 2 1 -1 ]       [ 1 ]
    [ 1 -1 2 ]       [ 5 ]
Paso 2: Calculamos det(A)
(+) = (1)(1)(2) + (2)(-1)(1) + (1)(2)(-1) = 2 - 2 - 2 = -2
(-) = (1)(1)(1) + (1)(-1)(2) + (2)(2)(-1) = 1 - 2 - 4 = -5
det(A) = -2 - (-5) = 3
Paso 3: Calculamos det(A₁)
A₁ = [ 6 2 1 ]
     [ 1 1 -1 ]
     [ 5 -1 2 ]

(+) = (6)(1)(2) + (2)(-1)(5) + (1)(1)(-1) = 12 - 10 - 1 = 1
(-) = (1)(1)(5) + (6)(-1)(-1) + (2)(1)(2) = 5 + 6 + 4 = 15
det(A₁) = 1 - 15 = -14
Paso 4: Calculamos det(A₂)
A₂ = [ 1 6 1 ]
     [ 2 1 -1 ]
     [ 1 5 2 ]

(+) = (1)(1)(2) + (6)(-1)(1) + (1)(2)(5) = 2 - 6 + 10 = 6
(-) = (1)(1)(1) + (1)(-1)(5) + (6)(2)(2) = 1 - 5 + 24 = 20
det(A₂) = 6 - 20 = -14
Paso 5: Calculamos det(A₃)
A₃ = [ 1 2 6 ]
     [ 2 1 1 ]
     [ 1 -1 5 ]

(+) = (1)(1)(5) + (2)(1)(1) + (6)(2)(-1) = 5 + 2 - 12 = -5
(-) = (6)(1)(1) + (1)(1)(-1) + (2)(2)(5) = 6 - 1 + 20 = 25
det(A₃) = -5 - 25 = -30
Paso 6: Aplicamos las fórmulas
x = det(A₁) / det(A) = -14 / 3
y = det(A₂) / det(A) = -14 / 3
z = det(A₃) / det(A) = -30 / 3 = -10
✅ Solución: x = -14/3, y = -14/3, z = -10
✨💕

🎀 Resolución de Problemas Aplicados

📖 Cómo plantear problemas con sistemas de ecuaciones

Pasos para resolver problemas:

  1. Leer cuidadosamente el problema
  2. Identificar las incógnitas (¿qué buscamos?)
  3. Asignar variables a las incógnitas
  4. Traducir las relaciones del problema a ecuaciones
  5. Resolver el sistema de ecuaciones
  6. Verificar que la solución tenga sentido
💡 Nota de Pusheen: ¡Lo más importante es traducir bien las palabras a matemáticas! 🐱📝

✨ Problema 1: Números

Enunciado: La suma de dos números es 50 y su diferencia es 10. ¿Cuáles son los números?

Paso 1: Identificar incógnitas
- Primer número: x
- Segundo número: y
Paso 2: Plantear ecuaciones
- "La suma es 50": x + y = 50
- "Su diferencia es 10": x - y = 10
Paso 3: Resolver por reducción (sumar ambas)
(x + y) + (x - y) = 50 + 10
2x = 60
x = 30
Paso 4: Sustituir para hallar y
30 + y = 50
y = 20
✅ Respuesta: Los números son 30 y 20
🎀 Verificación:
30 + 20 = 50 ✓
30 - 20 = 10 ✓
🔢

✨ Problema 2: Edades

Enunciado: María tiene el doble de edad que Ana. Dentro de 5 años, la suma de sus edades será 40 años. ¿Qué edad tiene cada una ahora?

Paso 1: Identificar incógnitas
- Edad actual de María: M
- Edad actual de Ana: A
Paso 2: Plantear ecuaciones
- "María tiene el doble de edad que Ana": M = 2A
- "Dentro de 5 años la suma será 40": (M+5) + (A+5) = 40
Paso 3: Simplificar la segunda ecuación
M + A + 10 = 40
M + A = 30
Paso 4: Sustituir M = 2A en M + A = 30
2A + A = 30
3A = 30
A = 10
Paso 5: Calcular M
M = 2(10) = 20
✅ Respuesta: María tiene 20 años y Ana tiene 10 años
🎀 Verificación:
20 = 2(10) ✓
(20+5) + (10+5) = 25 + 15 = 40 ✓
👧

✨ Problema 3: Dinero y Precios

Enunciado: En una tienda, 3 cuadernos y 2 lapiceros cuestan $15. Si 2 cuadernos y 4 lapiceros cuestan $14, ¿cuánto cuesta cada artículo?

Paso 1: Identificar incógnitas
- Precio de un cuaderno: c
- Precio de un lapicero: l
Paso 2: Plantear ecuaciones
- "3 cuadernos y 2 lapiceros cuestan $15": 3c + 2l = 15
- "2 cuadernos y 4 lapiceros cuestan $14": 2c + 4l = 14
Paso 3: Resolver por reducción
Multiplicamos la primera ecuación por 2:
6c + 4l = 30
2c + 4l = 14

Restamos:
4c = 16
c = 4
Paso 4: Sustituir c = 4
3(4) + 2l = 15
12 + 2l = 15
2l = 3
l = 1.5
✅ Respuesta: Cada cuaderno cuesta $4 y cada lapicero cuesta $1.50
🎀 Verificación:
3(4) + 2(1.5) = 12 + 3 = 15 ✓
2(4) + 4(1.5) = 8 + 6 = 14 ✓
💰📝

✨ Problema 4: Mezclas

Enunciado: Se mezclan dos tipos de café: uno de $12 por kg y otro de $18 por kg. Si queremos obtener 10 kg de mezcla a $15 por kg, ¿cuántos kg de cada tipo debemos usar?

Paso 1: Identificar incógnitas
- Kg de café de $12: x
- Kg de café de $18: y
Paso 2: Plantear ecuaciones
- "Total 10 kg": x + y = 10
- "Precio de la mezcla": 12x + 18y = 15(10) = 150
Paso 3: De la primera: y = 10 - x
Paso 4: Sustituir en la segunda
12x + 18(10 - x) = 150
12x + 180 - 18x = 150
-6x = -30
x = 5
Paso 5: Calcular y
y = 10 - 5 = 5
✅ Respuesta: Se necesitan 5 kg de café de $12 y 5 kg de café de $18
☕

✨ Problema 5: Geometría

Enunciado: Un rectángulo tiene un perímetro de 40 cm. Si el largo es 4 cm más que el doble del ancho, ¿cuáles son sus dimensiones?

Paso 1: Identificar incógnitas
- Ancho del rectángulo: a
- Largo del rectángulo: l
Paso 2: Plantear ecuaciones
- "Perímetro = 40": 2l + 2a = 40 → l + a = 20
- "El largo es 4 más que el doble del ancho": l = 2a + 4
Paso 3: Sustituir l = 2a + 4 en l + a = 20
(2a + 4) + a = 20
3a + 4 = 20
3a = 16
a = 16/3 ≈ 5.33 cm
Paso 4: Calcular l
l = 2(16/3) + 4 = 32/3 + 12/3 = 44/3 ≈ 14.67 cm
✅ Respuesta: Ancho = 5.33 cm, Largo = 14.67 cm
💕✨
