🎀 Métodos Algebraicos para Sistemas de Ecuaciones

📖 ¿Qué es un sistema de ecuaciones lineales?

Un sistema de ecuaciones lineales es un conjunto de dos o más ecuaciones que comparten las mismas variables. Nuestro objetivo es encontrar los valores de estas variables que satisfagan todas las ecuaciones al mismo tiempo.

Sistema 2×2:
a₁x + b₁y = c₁
a₂x + b₂y = c₂
💡 Nota de Pusheen: ¡Imagina que cada ecuación es una línea! La solución es donde se cruzan estas líneas. ¡Miau! 🐱

🌟 Método de Sustitución

Este método consiste en despejar una variable de una ecuación y sustituirla en la otra.

🐱 → 📝

Pasos:

  1. Despeja una variable de cualquiera de las ecuaciones
  2. Sustituye esa expresión en la otra ecuación
  3. Resuelve la ecuación resultante
  4. Sustituye el valor encontrado en cualquier ecuación para hallar la otra variable

✨ Ejemplo Resuelto - Método de Sustitución

Resolver:

2x + y = 7
x - y = 2
Paso 1: Despejamos y de la primera ecuación
y = 7 - 2x
Paso 2: Sustituimos en la segunda ecuación
x - (7 - 2x) = 2
x - 7 + 2x = 2
3x = 9
x = 3
Paso 3: Sustituimos x = 3 en y = 7 - 2x
y = 7 - 2(3)
y = 7 - 6
y = 1
✅ Solución: x = 3, y = 1
🎀 Verificación:
2(3) + 1 = 7 ✓
3 - 1 = 2 ✓

🌸 Método de Igualación

Este método consiste en despejar la misma variable de ambas ecuaciones e igualar las expresiones.

Pasos:

  1. Despeja la misma variable de ambas ecuaciones
  2. Iguala las dos expresiones obtenidas
  3. Resuelve la ecuación resultante
  4. Sustituye el valor encontrado para hallar la otra variable

✨ Ejemplo Resuelto - Método de Igualación

Resolver:

3x + 2y = 12
2x + y = 7
Paso 1: Despejamos y de ambas ecuaciones
De la primera: 2y = 12 - 3x → y = (12 - 3x)/2
De la segunda: y = 7 - 2x
Paso 2: Igualamos
(12 - 3x)/2 = 7 - 2x
Paso 3: Resolvemos
12 - 3x = 2(7 - 2x)
12 - 3x = 14 - 4x
4x - 3x = 14 - 12
x = 2
Paso 4: Sustituimos x = 2
y = 7 - 2(2)
y = 7 - 4
y = 3
✅ Solución: x = 2, y = 3

💖 Método de Reducción (Eliminación)

Este método consiste en multiplicar las ecuaciones por números adecuados para que al sumarlas o restarlas, se elimine una variable.

Pasos:

  1. Multiplica una o ambas ecuaciones por números que hagan iguales los coeficientes de una variable
  2. Suma o resta las ecuaciones para eliminar esa variable
  3. Resuelve la ecuación de una variable resultante
  4. Sustituye el valor encontrado para hallar la otra variable

✨ Ejemplo Resuelto - Método de Reducción

Resolver:

4x + 3y = 18
2x - y = 4
Paso 1: Multiplicamos la segunda ecuación por 3
4x + 3y = 18
6x - 3y = 12
Paso 2: Sumamos ambas ecuaciones
(4x + 3y) + (6x - 3y) = 18 + 12
10x = 30
x = 3
Paso 3: Sustituimos x = 3 en 2x - y = 4
2(3) - y = 4
6 - y = 4
y = 2
✅ Solución: x = 3, y = 2

🎀 Operaciones con Matrices

📖 ¿Qué es una Matriz?

Una matriz es un arreglo rectangular de números organizados en filas y columnas. Se representa con letras mayúsculas.

Matriz A de orden 2×3:

A = [ a₁₁ a₁₂ a₁₃ ]
    [ a₂₁ a₂₂ a₂₃ ]
💡 Nota de Pusheen: El orden de una matriz se escribe como filas × columnas. ¡Es como una cuadrícula de gatitos! 🐱

➕ Suma y Resta de Matrices

Dos matrices se pueden sumar o restar solo si tienen el mismo orden. La operación se realiza elemento a elemento.

Si A = [aᵢⱼ] y B = [bᵢⱼ]
Entonces: A ± B = [aᵢⱼ ± bᵢⱼ]

✨ Ejemplo Resuelto - Suma de Matrices

Datos:
A = [ 2 3 ]    B = [ 1 4 ]
    [ 1 5 ]       [ 2 3 ]
Solución:
A + B = [ 2+1 3+4 ]
        [ 1+2 5+3 ]
✅ Resultado:
A + B = [ 3 7 ]
        [ 3 8 ]

✖️ Multiplicación de una Matriz por un Escalar

Para multiplicar una matriz por un número (escalar), multiplicamos cada elemento de la matriz por ese número.

k · A = [k · aᵢⱼ]

✨ Ejemplo Resuelto - Producto por Escalar

Datos:
A = [ 2 -1 ]    k = 3
    [ 4 3 ]
Solución:
3 · A = [ 3(2) 3(-1) ]
        [ 3(4) 3(3) ]
✅ Resultado:
3 · A = [ 6 -3 ]
        [ 12 9 ]

🔢 Multiplicación de Matrices

Dos matrices A y B se pueden multiplicar si el número de columnas de A es igual al número de filas de B.

Si A es m×n y B es n×p
Entonces: C = A · B es m×p

cᵢⱼ = Σ(aᵢₖ · bₖⱼ)
💡 Nota de Pusheen: Cada elemento de C se obtiene multiplicando fila por columna. ¡Es como hacer sumas de productos! 🐱✨

✨ Ejemplo Resuelto - Multiplicación de Matrices

Datos:
A = [ 1 2 ]    B = [ 3 1 ]
    [ 3 4 ]       [ 2 5 ]
Paso 1: Elemento c₁₁ (fila 1 × columna 1)
c₁₁ = 1(3) + 2(2) = 3 + 4 = 7
Paso 2: Elemento c₁₂ (fila 1 × columna 2)
c₁₂ = 1(1) + 2(5) = 1 + 10 = 11
Paso 3: Elemento c₂₁ (fila 2 × columna 1)
c₂₁ = 3(3) + 4(2) = 9 + 8 = 17
Paso 4: Elemento c₂₂ (fila 2 × columna 2)
c₂₂ = 3(1) + 4(5) = 3 + 20 = 23
✅ Resultado:
A · B = [ 7 11 ]
        [ 17 23 ]

🔄 Matriz Identidad y Matriz Inversa

Matriz Identidad (I): Es una matriz cuadrada con unos en la diagonal principal y ceros en el resto.

I₂ = [ 1 0 ]    I₃ = [ 1 0 0 ]
     [ 0 1 ]         [ 0 1 0 ]
                            [ 0 0 1 ]

Matriz Inversa (A⁻¹): Es la matriz que al multiplicarla por A da la matriz identidad.

A · A⁻¹ = I
